# SHEDOW AI Platform - API Documentation

## Base URL

```
Production: https://api.shedow.ai
Staging: https://staging.api.shedow.ai
Local: http://localhost:3000
```

## Authentication

All API requests require a valid JWT token in the Authorization header:

```bash
Authorization: Bearer <jwt_token>
```

## Core Endpoints

### 1. Process Input

**Endpoint:** `POST /ai/process`

**Request:**
```json
{
  "input": "What time is it?",
  "context": {
    "userId": "user_123",
    "location": "New York",
    "preferOffline": false
  }
}
```

**Response:**
```json
{
  "output": "It's 3:45 PM",
  "source": "plugin",
  "processingTime": 245,
  "memoryStored": true,
  "conversationId": "conv_789"
}
```

**Sources:**
- `plugin` - Executed by plugin system
- `offline` - Generated by offline LLM
- `cloud` - Generated by cloud AI (GPT-4o)

### 4. Install Plugin

**Endpoint:** `POST /plugins/install`

**Request:**
```json
{
  "pluginId": "custom_plugin",
  "url": "https://plugins.shedow.ai/custom-plugin.jar"
}
```

**Response:**
```json
{
  "success": true,
  "pluginId": "custom_plugin",
  "message": "Plugin installed successfully"
}
```

  "preferences": {

### 6. Update Preferences

**Endpoint:** `PUT /user/preferences`

**Request:**
```json
{
  "preferOffline": true,
  "language": "es-ES",
  "ttsPitch": 0.9
}
```

**Response:**
```json
{
  "success": true,
  "preferences": {...}
}
```

## Error Responses

### 400 Bad Request
```json
{
  "error": "INVALID_INPUT",
  "message": "Input cannot be empty",
  "code": 400
}
```

### 401 Unauthorized
```json
{
  "error": "UNAUTHORIZED",
  "message": "Invalid or missing authentication token",
  "code": 401
}
```

### 429 Too Many Requests
```json
{
  "error": "RATE_LIMITED",
  "message": "Too many requests. Try again in 60 seconds.",
  "code": 429,
  "retryAfter": 60
}
```

### 500 Server Error
```json
{
  "error": "INTERNAL_ERROR",
  "message": "An unexpected error occurred",
  "code": 500,
  "requestId": "req_abc123"
}
```

## WebSocket API (Real-time)

### Connect
```javascript
const ws = new WebSocket('wss://api.shedow.ai/ws');
ws.onopen = () => {
  ws.send(JSON.stringify({type: 'auth', token: jwt_token}));
};
```

### Send Voice Data
```javascript
ws.send(JSON.stringify({
  type: 'voice_chunk',
  audio: base64_encoded_chunk
}));
```

### Receive Response
```javascript
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'response') {
    console.log(data.output);
  }
};
```

## SDK Usage

### Android SDK
```kotlin
val shedow = ShedowAI.Builder(context)
  .setApiKey("your_api_key")
  .setPreferOffline(false)
  .build()

val response = shedow.process("What time is it?")
Log.d("SHEDOW", response.output)
```

### JavaScript SDK
```javascript
const shedow = new ShedowAI({apiKey: 'your_api_key'});

const response = await shedow.process('What time is it?');
console.log(response.output);
```
