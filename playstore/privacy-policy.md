# Privacy Policy - SHEDOW AI

## Introduction

SHEDOW AI ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains our practices regarding data collection and usage.

## 1. Information We Collect

### Voice Commands
- **Recording**: Only recorded when microphone permission is granted and app is active
- **Processing**: Voice is converted to text for processing
- **Storage**: Voice audio is NOT stored on our servers
- **Cloud Processing**: Text is sent to OpenAI for advanced queries (optional)

### Device Information
- Device model, OS version
- App usage statistics
- Crash reports (for improvement)

### User Settings
- Language preferences
- Voice settings
- Offline/online mode preference

## 2. Data Usage

### Offline Mode
- All processing happens locally on your device
- No data leaves your phone
- Zero connectivity required

### Cloud Mode
- Queries sent to OpenAI API
- Governed by OpenAI Privacy Policy
- User can opt out anytime

### Memory
- Conversation history stored locally
- Users can delete anytime
- Never sold to third parties

## 3. Permissions

### Required
- **RECORD_AUDIO**: For voice input (microphone)
- **INTERNET**: For cloud AI features

### Optional
- **CALL_PHONE**: For phone control features
- **SEND_SMS**: For message features
- **LOCATION**: For location-based features

## 4. Data Deletion

Users can:
1. Delete local conversation history anytime
2. Opt out of cloud processing
3. Revoke microphone permissions
4. Request complete account deletion

## 5. Third-Party Services

- **OpenAI API**: For advanced AI processing
- **Google Speech Recognition**: For voice-to-text
- **Porcupine**: For wake word detection

## 6. Security

- End-to-end encryption for cloud queries
- Secure API communication (HTTPS/TLS)
- No unauthorized data sharing
- Regular security audits

## 7. Children's Privacy

SHEDOW AI is not intended for users under 13. We don't knowingly collect data from children.
